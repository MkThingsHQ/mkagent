MkAgent 源码迁移与质量审计报告

MkAgent 是以 Craft Agents OSS 为固定上游、保留 Desktop/WebUI/CLI 与 WebSocket RPC 架构、裁掉非核心产品面的 Pi-only Lite 版本。共享架构和 UI 组件应尽量与 Craft 同路径同实现，差异只来自品牌、明确裁剪项和运行边界。

仓库结构

这是一个 Bun workspace monorepo，桌面端、WebUI、CLI、服务核心、Pi runtime 与共享组件按边界分层。

架构设计

Electron、WebUI 与 CLI 是同一 RPC 能力面的不同客户端，业务行为集中在 server-core 与 shared。

Electron renderer ─┐ WebUI ──────────────┼─> WebSocket RPC ─> server-core ─> shared/core ─> Pi runtime CLI ────────────────┘ │ └─> config / sessions / skills
