默认视图：完整拓扑

所有入口共享同一套 RPC 和会话运行时；差异主要在入口适配与平台能力。

一条主链，三种入口

Desktop 内嵌本地 server；WebUI 由 headless server 托管；CLI 可连接既有实例或临时拉起 server。进入 RPC 后，三者复用相同的 workspace、SessionManager 和 Pi backend。

关键隔离点

  • 客户端与 host：鉴权 WebSocket RPC
  • host 与 agent：stdio JSONL 子进程
  • agent 与模型：Pi SDK 经 HTTPS / 本地端点
