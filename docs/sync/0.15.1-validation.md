## Additional corrections found by runtime verification / 运行验证发现并修复

1. MkAgent's Lite browser bridge had not enabled agent control, so it did not activate the new hidden-page rendering behavior. The retained bridge now sets it before browser actions. Its regression first failed, then passed after the fix.
2. Upstream supplied Windows virtual-key values as native key codes too. On macOS, a real hidden BrowserView silently dropped Backspace (no keydown event); letting Chromium derive the native code produces the expected key event and edits `abc` to `ab`. The regression first failed, then passed.
3. A timer from the previous CDP command could detach the debugger during a later pending command. Commands now suspend idle detachment until every in-flight call finishes; a 5.1-second pending-command regression first failed, then passed.
4. A never-shown macOS BrowserView can have no native capture surface and Electron can leave capturePage pending indefinitely. A bounded capture returns the existing actionable error, restores the hidden window and releases temporary capture state. The real first-surface failure was exercised; a separate window primed by initial display passes hidden current-frame captures. This is not claimed as fully invisible first-surface capture support, and focus alone did not recover the already-stalled instance in the local harness.
