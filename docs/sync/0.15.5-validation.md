## Implementation / 实现

- Default zoom: Appearance offers 80/90/100/110/125/150%; invalid/nonfinite values fall back to 100, finite values snap/clamp. Main IPC reads/writes local `preferences.json`; preload methods are excluded precisely from RPC parity, and WebUI has no methods or zoom setting. Native menu and RPC Reset both use the stored default. Every new window sets its initial zoom baseline, reapplies before first show and after loads. Actual restart testing caught the first-show reset left by the upstream load-only implementation; the first-show hook fixes it.
- Message copy: shared clipboard feedback hook cancels timers on unmount and repeated copying. User bubbles retain attachments/Markdown/badges and expose the same accessible button style as responses on hover/focus/touch; compact bubbles omit it as upstream does. MkAgent copies `content`, not badge-stripped `displayContent`, to preserve the input text.
- Workspace confirmation: desktop and compact switchers close their picker before showing a Cancel-focused dialog. Folder, platform file-manager action and Add Workspace → Open folder instructions are shown. WebUI does not offer removal. Actual storage unregisters only, preserving root and legacy session directories; folder identity survives reopening, including older mismatched registration IDs. RPC rejects the calling workspace and workspaces still open in other windows. No forced window close or real user-data deletion is performed.
- Context menus: registered on application-window webContents in every build. Editable fields use native Cut/Copy/Paste/Select All roles; selected text gets Copy; http/https/mailto links get Copy Link; misspellings get suggestions and Learn Spelling. Inspect is development-only. External browser-pane webContents are separate and do not inherit the app-shell handler.
- Grouping: retained unread groups each get their own recent-session window. Collapsed counts do not consume expanded groups' limits; date grouping keeps one chronological window. Four upstream status/project-only test cases are excluded precisely, with an extra unread-collapse case added; no ignore pattern is widened.
- Documentation: MkAgent clone/release URLs already use MkThingsHQ; no stale lukilabs/anthropics or Docker image references exist in retained docs. Upstream Dockerfile/CONTRIBUTING/playground and Docker distribution claims do not apply. No unpublished MkAgent image is advertised. Release workflow continues reading the baseline from the source manifest; CI and drift baseline are pinned to v0.15.5.
