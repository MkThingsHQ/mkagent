Source-driven starter suggestions are replaced with local files, web news and Skills. Existing MkAgent `spawn_session` child sessions remain separate sessions with parent permission clamping; this sync does not import the excluded conductor/workflow engine.

CI packaging is build evidence, not native UI or notarization evidence.

Lint warnings are reported separately from errors; no new ignore pattern is used to conceal an applicable upstream implementation or regression test. No v0.15.1/v0.15.2 feature is included.
