## Exclusions and limits / 排除与边界

Claude SDK/CLI settings, Sources/MCP, Pages, Projects/conductor, Automations, Viewer/public sharing, labels/custom statuses and messaging remain excluded. Decision/Guarded remain deferred. Craft Discord/product release notes and absent locales/workspaces are not restored. Shared files are evaluated per hunk; applicable Pi configuration, Skills and attachment paths are retained.

The image decoder is JS plus embedded WASM and is bundled into Desktop/headless builds, avoiding a native libheif deployment requirement. Local native UI runs on macOS; Linux CI exercises the actual decoder/runtime suite, while Windows/Linux packaging is separate evidence from native UI interaction. This does not claim every HEIC encoder/profile or platform UI is tested. OpenCode's remote API, external paid credentials and commercial billing are not tested. The local endpoint has zero model pricing; nonzero arithmetic remains covered by synthetic accounting tests.

No release tag or formal Release is created for this synchronization.
