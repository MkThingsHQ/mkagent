## Retained implementation / 保留实现

- Session families: spawned sessions and branches nest under their parent/source. Orphans remain roots; corrupt cycles are broken. Families remain whole across date/unread grouping and weighted pagination. Per-workspace collapse persistence, tree guides, descendant counts, keyboard reveal and hidden-row multi-selection cleanup are retained without labels, projects or custom statuses. `branchFromSessionId` is computed from persisted source paths rather than added to disk headers.
- Coding: register the retained browser, Mermaid validation, data transformation, focused LLM and spawn/get/list session tools through the same profile-filtered Pi schemas and execution path. Standard/Coding prompts share the existing data/LLM/document/preview guidance, and browser guidance follows its setting. Pages and Sources tools stay absent. Spawned sessions inherit the parent folder and explicit Coding mode (including `false`), preserve explicit model/folder overrides, and keep permission clamping.
- Pi: replace the entire proxy set, suppress identical registrations and synchronize before each prompt. Tool changes wait for compaction and defer rebuilding while busy. A branch forks from its parent once, writes its cutoff as a non-context entry and subsequently reopens its own history.
- Images: macOS uses ImageIO through `sips` to convert profiled HEIC/HEIF to upright sRGB JPEG; Windows/Linux and macOS decoder failure retain the portable fallback. Real macOS rotated Display P3 fixtures check orientation and pixel colors.
- Session loading: bounded async disk reads skip cloud-evicted files from metadata and apply a two-second per-header timeout. Error paths close descriptors. Preserve the MkAgent full-first-line reader so PR pins/cursors and multibyte data beyond 8KB survive. The small Lite manager retains its existing single initialization gate, and list consumers still await disk discovery; the full Craft dual-gate startup architecture is not copied.
- Permissions: Explore rejects unknown tools, blocks isolated subagents and does not infer external tool permissions from read-only suffixes. Monitor shell commands use the same Explore/Ask checks as Bash; WebSocket-only watches remain read-only. Guarded runtime remains excluded.
