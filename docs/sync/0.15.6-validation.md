## Implementation / 实现

- PR tools: all four Coding-only definitions flow through Pi JSON Schema registration, profile-filtered execution, session callbacks, server operations, channel-map and UI. `pr_status` reuses the live header snapshot; without a subscription it fetches once. Other-session reads are cache-only. `pr_bind` verifies before persisting; canonical ids dedupe branch/pinned coordinates. A real Pi Bash completion now retains its command by tool-call id, because the Lite adapter's result event has no input; successful `gh pr create` can therefore bind the extra PR. Failure/non-Coding paths do not pin.
- Auto-merge: the tool description requires explicit user intent for enabling or disabling; it is never inferred from a code/review fix request. Explore blocks writes. Server-side GitHub mutations select only allowed merge methods and report refusal reasons; the card exposes the same operation. Automated tests use controlled responses, never real PR mutations.
- Multi-PR UI: branch first, then ordered pins; tabs, overflow +N, urgent-state priority, arrows, Pinned/Unpin and link copy. Generic tab sizing is extracted without restoring label UI; hidden tabs leave keyboard focus. Pinned Resolve/Fix/Fix CI prompts require an existing worktree, a new detached worktree or separate clone and preserve the current branch/files. Actual local Git fixtures cover all three strategies with a fork head and dirty original checkout. This is a prompt-directed agent workflow, not an OS-enforced checkout sandbox or a commercial-model reasoning evaluation.
- Auto review fix: explicit per-PR opt-in; own-branch only; a server subscription plus independent five-minute timer continues while another session/window is active or hidden. Trusted OWNER/MEMBER/COLLABORATOR identities count; viewer replies, untrusted or missing identities do not. Busy/Explore/conflicts wait. After asynchronous lookups, the monitor rechecks the setting, session, directory, permissions and actual branch/repository before dispatch. It serializes evaluations, avoids duplicate feedback/runs across sessions watching the same PR, retains cumulative feedback cursors, restores on startup and disarms on Off, confirmed PR changes, deletion and teardown. Timers do not catch up missed intervals after sleep. Hidden notices retain existing permissions and explicitly prohibit comment-supplied commands/links and unauthorized push/reply/resolve/merge/auto-merge actions.
- Persistence: `boundPrs` and `prMonitors` are included in session field selection, runtime restoration and DTOs. Sync/async header readers read the complete first line, so >8KB PR/cursor metadata and multibyte text survive listing/restart. App-generated hidden notices are excluded from preview/role metadata.
- Discovery: breadth-first four-level search under the workspace default/recent-repo parents; stop at repositories, skip node_modules/Library/hidden/workspace data, avoid symlink cycles, dedupe shared Git directories and support bare layouts/tilde paths. Async IO, deadline checks inside broad batches and timed Git calls share one two-second budget; partial results return without blocking the renderer.
- Coding continuation: create and navigate immediately; generate the source summary in the background. Reserve the first send before persistence/awaits, queue subsequent messages in order, wait at most 30 seconds and reject late context after timeout/deletion. Cancellation never starts the waiting turn or clears a newer turn. Summaries remain one-shot hidden context. Existing Stop/background work semantics stay intact.
- Claude-only config forwarding was inspected by hunk. Pi already forwards the whole BackendConfig, applies its SDK image processing and retained compaction/context metering. The actual Pi Read path resizes an image above 3.75MB successfully. No Claude SDK is restored. The shared PR export and applicable EN/ZH strings/styles/tests are retained.

## Scope and limits / 范围与限制

Preserve MkAgent Pi/Lite branding, local configuration, Pi 1.1.0, v0.15.4 Coding/worktree/async Git and v0.15.5 zoom/copy/workspace confirmation/context menus/unread grouping, plus earlier HEIC/HEIF, maxTokens, compaction, Skills, billing/forks and browser/Stop. Sources/MCP OAuth relay, Pages, Projects/conductor, product Automations, public sharing, labels/custom statuses and messaging remain excluded; Decision/Guarded remain deferred. Coding PR Auto review fix is explicitly included.

Native interaction is macOS-only; Windows/Linux packaging is checked by PR CI, not native interaction. Screen locking, OS sleep/resume and commercial-provider behavior are not manually simulated: scheduling/recovery use server timers and controlled lifecycle fixtures. GitHub responses/auto-merge mutations in tests are fixtures; real repository listing, when used, is read-only. Inherited GitHub query windows remain bounded (100 review threads, five latest comments per thread and 20 opinionated reviews), so exceptionally large reviews may need manual follow-up. Local fork/worktree fixtures validate checkout preservation; autonomous model decisions across every fork/remote layout are not claimed.
