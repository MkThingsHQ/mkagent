# MkAgent 0.1.0

MkAgent is a lightweight Craft Agent distribution focused on local agent workflows.

- Run the same workspace and session experience in Desktop and WebUI.
- Connect OpenAI-compatible providers, including DeepSeek, through the Pi backend.
- Use skills, browser tools, document tools, permissions, themes, and workspace settings.
- Keep sessions local with search, flags, archives, import, export, and branching.
